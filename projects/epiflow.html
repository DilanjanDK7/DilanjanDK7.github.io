EpiFlow

Epilepsy research pipeline: preprocessing and feature extraction for fMRI.

← Back to Home

Overview

EpiFlow is a combined pipeline for processing fMRI data for epilepsy research, integrating fMRIPrep for preprocessing and a custom suite for feature extraction. Developed by Dilanjan DK at Western University.

Key Features

  • Automated DICOM to BIDS conversion (optional)
  • Preprocessing with fMRIPrep (Docker-based)
  • Feature extraction: ALFF, ReHo, Hurst, Fractal Dimension, QM-FFT, RSN
  • Flexible configuration and modular execution
  • Comprehensive documentation and troubleshooting guides
